# WHYRO Community

A dark, green-accented community platform starter for publishing and discovering projects.

## Included
- Custom WHYRO vector logo and favicon
- Animated launch screen and motion-aware UI
- Responsive homepage, category filters, and project search
- Supabase Google OAuth integration
- Supabase-backed project publishing
- Contributor application form
- Initial database schema and row-level security policies
- Deployment and security setup notes

## Not yet production-complete
Email notifications, protected admin approval, project file uploads, editing/deleting projects, and full moderation need their server-side configuration and additional implementation. See `SETUP.md`.

Run `npm install`, configure `.env`, then `npm run dev`.
